# Pearl AI Sale Page (Advance) — ออเดอร์ตกฐานข้อมูลจริง + แอดมินตรวจสลิป

ต่อยอดจากหน้าขายไฟล์เดียว + Google Sheet (เล่ม 01) ขึ้นไปอีกขั้น — ออเดอร์ตก **Supabase** (ฐานข้อมูลจริง ฟรี) · ลูกค้าโอนแล้ว**แนบสลิปได้เลงในหน้าเดียว** · เจ้าของร้านเปิด **หน้าแอดมิน** ดูออเดอร์ ดูสลิป เปลี่ยนสถานะ จากมือถือ · deploy ขึ้น **Vercel ผ่าน git** (push แล้วเว็บอัปเดตเอง)

ประกอบอีบุ๊ก **"หน้าขายด้วย AI เล่ม 02 · ออเดอร์ตกฐานข้อมูลจริง + แอดมินตรวจสลิป"** โดย Work With AI Lemon

## โครงระบบ

```text
[หน้าขาย index.html]
  ลูกค้ากรอกฟอร์ม → ออเดอร์ตกตาราง orders (Supabase)
  โอนเงิน → แนบรูปสลิป → ขึ้น storage bucket "slips" (ส่วนตัว)
                    ↓
[หน้าแอดมิน admin.html]  (ล็อกอินด้วย Supabase Auth)
  ดูออเดอร์ล่าสุด · เปิดสลิปผ่านลิงก์ชั่วคราว · เปลี่ยนสถานะ
  รอตรวจสลิป → ชำระแล้ว → จัดส่งแล้ว (หรือยกเลิก / COD รอจัดส่ง)
```

ความปลอดภัยมาจาก **RLS (Row Level Security)** ไม่ใช่การซ่อน key — คนทั่วไป (anon) แจ้งออเดอร์และแนบสลิปได้อย่างเดียว อ่านออเดอร์ของคนอื่นไม่ได้ เปลี่ยนสถานะไม่ได้ เห็นสลิปไม่ได้ มีแค่ทีมร้านที่ล็อกอินเท่านั้นที่ดูได้ครบ

## ตั้งค่าครั้งเดียว ประมาณ 20 นาที

### 1 · สร้างโปรเจกต์ Supabase (5 นาที)

1. สมัครที่ supabase.com (แผนฟรีพอสำหรับร้านเล็ก ๆ ) → New project
2. ตั้งชื่อโปรเจกต์ เช่น `dripno9-shop` · ตั้ง database password เก็บไว้ให้ดี
3. รอสักครู่ให้ระบบสร้างโปรเจกต์เสร็จ

### 2 · สร้างตาราง + กำแพงความปลอดภัย (3 นาที)

ใน Dashboard → **SQL Editor** → วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งหมด → **Run** — จบ ได้ทั้งตาราง orders, RLS, และที่เก็บสลิป

### 3 · สร้างบัญชีแอดมิน (2 นาที)

Dashboard → **Authentication → Users → Add user** → กรอกอีเมล + รหัสผ่านของเจ้าของร้าน (ใช้เข้าหน้า admin.html — หนึ่งร้านมีสัก 1–2 บัญชีพอ)

### 4 · เชื่อมเว็บเข้ากับฐานข้อมูล (2 นาที)

Dashboard → **Settings → API** → ก๊อป 2 ค่า

- Project URL → แก้ `SUPABASE_URL` ใน `config.js`
- anon public key → แก้ `SUPABASE_ANON_KEY` ใน `config.js`

(อย่าสับสน — anon key ออกแบบให้อยู่บนหน้าเว็บได้ ตัวคุมความปลอดภัยคือ RLS จากขั้นที่ 2)

### 5 · Deploy ขึ้น Vercel ผ่าน git (8 นาที)

1. push repo นี้ขึ้น GitHub ของคุณ
2. vercel.com → Add New → Project → เลือก repo → **Deploy** (ไม่ต้องตั้งค่าอะไรเพิ่ม เว็บเป็น static)
3. ได้ลิงก์ `ชื่อ-โปรเจกต์.vercel.app` — หน้าขายอยู่ที่ `/` หน้าแอดมินอยู่ที่ `/admin.html`
4. **จากนี้ทุกครั้งที่แก้โค้ดแล้ว push เว็บอัปเดตเองภายในหนึ่งนาที** — นี่แหละคือ "deploy ผ่าน git"

### 6 · ทดสอบให้ครบวงจร

1. เปิดหน้าขายจากมือถือ → สั่งจริง 1 ชิ้น (โอนเงิน) → แนบรูปอะไรก็ได้เป็นสลิป
2. เปิด `/admin.html` จากมือถืออีกเครื่อง → ล็อกอิน → ต้องเห็นออเดอร์ + เปิดสลิปได้ → กด "ชำระแล้ว"
3. แก้เลขบัญชีจริงใน `index.html` (ค้นหาคำว่า `BANK`) → push → เสร็จ
